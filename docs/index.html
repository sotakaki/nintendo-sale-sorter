データはニンテンドーストアの検索APIから取得。価格・値引き率は取得時点のもの。「最大◯%OFF」はパッケージ版/DL版などで率が異なる商品。
Steamレビューはタイトル名の自動マッチングによる参考情報(Switch版の評価ではありません)。クリックでSteamページを開きます。
「過去最安」は2026-08-14からの自前トラッキングによるもので、それ以前のセール履歴は含みません。
判定表記はゲームカタログ@Wikiの判定(タイトル名の自動マッチング)。クリックで該当記事を開きます。「クソゲーオブザイヤー」はKOTY据置Wikiの受賞歴です。
各カード下部のメーカー名の下に、同メーカーの現セール中作品の最高評価(↑)と最低評価(↓)を表示しています。色は出典: Steam(〜%) / PS Store(★〜) / ゲームカタログ@Wiki(判定語) / クソゲーオブザイヤー(KOTY〜)。表記形式でも判別できます。クリックで該当作品のページへ。
「PS ★」はPlayStation Store(日本)の星評価と現在価格(自動マッチング・参考情報。Switch版の評価ではありません)。クリックでPS Storeを開きます。
